# Candidate profile (used by JobPilot to score job fit)

Copy this file to `profile.md` (git-ignored) and fill it in. n8n reads it on every run.

## Target role
- e.g. Senior Product Manager / Lead PM
- Not: e.g. junior, internship, working student, project manager

## Experience
- Years in product, domains, biggest outcomes, team and P&L size
- Tools and technical skills

## Strong fit
- Domains and problem areas you want

## Weaker fit
- Domains you want to avoid

## Constraints
- Languages and levels
- Location and remote preferences
- Work permit
